# HISTORY NETWORK v5.3 — Editorial Taxonomy

Replaces repeated dot grids with individually rendered image/typographic cards at readable zoom, retaining discipline sections and historical node types.

- Mobile opens zoomed into the central network region instead of shrinking all 447 records to fit. Pinch to zoom and drag to explore; use the fit button to see the whole map.
- Every node can render as a card, including nodes without images; available images are shown inside cards.
- Wikidata QID P18 and exact-title Wikipedia thumbnail retrieval; no guessed image associations. Remote image availability is not guaranteed.
- Real recorded relations only (225 provisional edges); select a node to highlight its connections, or enable all lines in settings.
- Original single-file offline-capable core: data, CSS and JavaScript embedded in index.html. External network only for optional images.
- Existing chronology, bilingual interface, touch gestures, inspector and settings retained.
- NOTE: Syntax checked; not yet verified on an iPhone browser. Historical data remains provisional.
