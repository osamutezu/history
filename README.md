# HISTORY NETWORK v6.1 — MOVEMENT LAYERS

最新のv6.0から更新。既存の447件と225暫定関係、系譜図、年表、ネットワーク、日英UIを維持。

- 系譜図の各年代帯に「その年代に始まった文化運動」と「終了年が登録され、当該年代まで続く文化運動」を表示する横断リボンを追加。
- 文化運動のリボンを押すと該当ノードへ移動し、登録済みの関係を選択表示。
- START/CONTINUESを区別。活動期間未登録の運動を推定して延長しない。
- 登録数と該当する運動数を年代帯に表示。
- これらは登録データの年代上の重なりであり、流行度・影響力・先駆者の歴史的認定ではない。
