07 / DATA INGESTION

08 / WIKIDATA DISCOVERY

Generate a Wikidata SPARQL query for one discipline. Run it in Wikidata Query Service, download CSV, then import it below. This does not claim to verify influence relations.

Requires an internet connection for querying; CSV import works offline. Dates are treated as approximate start years, not verified activity dates.

09 / WORKS & MOVEMENTS DISCOVERY

Search Wikidata for authored works, architectural works, or movements. Import as provisional nodes. This does not infer historical influence.

10 / CREATOR RELATIONSHIPS

Import documented Wikidata creator/author statements (P50, P170, P84). Only links between already registered entities are added; imported statements remain UNVERIFIED until reviewed.

Query Wikidata, download CSV, then import. Import entities first if necessary.

11 / FILTERS

Dataset audit and JSON import/export. Click a connection to inspect its evidence records. Filter by evidence status. Newly added entities are editorial seed records, not independently verified; no inferred links are generated. Existing links remain unverified. Milestone years are not birth years. Historical relations are provisional. Node dates may indicate representative activity rather than birth/death. Verify sources before citation.
